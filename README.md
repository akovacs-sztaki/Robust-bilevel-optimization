*Robust bilevel optimization*


The repository contains problem instances and corresponding results for robust bilevel optimization. Two applications are considered: demand response management [1] and toll setting in networks [2]. The problem instances were used in computational experiemnts in the following papers:

[1] Kis, T.; Kovács, A.; Mészáros, Cs.: Robust bilevel optimization: algorithms, complexity and application. Optimization, 74(12):2951-2990, 2025.
https://doi.org/10.1080/02331934.2025.2468405
https://akovacs.pages.sztaki.hu/publications/Optimization2025.pdf

[2] Kovács, A.; Kis, T.: Robust bilevel toll setting in networks. Working paper, 2026.
